# Leads Tracker

A simple Chrome extension for saving and managing potential leads directly from your browser.

## Features

- Save leads with a single click
- Store lead information for later
- View your saved leads
- Delete leads when they are no longer needed
- Simple and lightweight Chrome extension

## Technologies

- HTML
- CSS
- JavaScript
- Chrome Extension APIs

## Installation

1. Clone this repository.
2. Open `chrome://extensions/` in Google Chrome.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the project folder.

The extension will then appear in your Chrome extensions.

## Usage

Use the extension to save potential leads while browsing and keep them organized for future follow-up.
